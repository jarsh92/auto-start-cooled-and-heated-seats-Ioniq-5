# Auto Seat 2.0 design

The approved design is implemented in the released app: centered graphite panel, Ford Blue navigation and ventilation, Classic heater red #C62828, matching Blue Frame seat icon, consistent On / Off labels, and paired individual Apply controls on both pages. The application and launcher label are Auto Seat; version information is 2.0 (Android internal build 13).

The owner reported the installed build works and looks great on the intended US-market car on November 13, 2026. Refer to the root README, COMPATIBILITY.txt and VALIDATION-2.0.md for scope and limitations. Physical panel width is approximate. The earlier browser prototype is retained as design history and is not the running Android app.
